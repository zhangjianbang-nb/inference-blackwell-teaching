## 一、这个站解决什么问题

推理上线时真正决定成败的是四张表：**精度选型表、KV/显存预算表、批调度表、并行拓扑表**。
论文里写"我们用了 FP8"，但没人告诉你缩放粒度怎么定、哪些层必须留 BF16、KV 怎么分页、
连续批处理怎么和 chunked prefill 抢 lane、尾延迟怎么压、GB200 NVL72 上专家并行怎么切。

这个站把七个领域的这些"脏活"拆开讲透，且**只讲 NVIDIA Blackwell 方案**：
SM100/SM103 的 tcgen05、TMEM、2-SM MMA、NVFP4/FP8、NVLink 5、NIXL，
以及 TensorRT-LLM / vLLM / SGLang / Dynamo / Triton / CUTLASS 的实现取舍。
